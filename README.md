# ChillTalk

**简体中文** | [English](README.en.md)

macOS 菜单栏语音输入。轻按快捷键开始说话，再按一次结束，润色后的文字直接出现在光标处。

主打**专业名词识别**：个人词库、纠正学习、按发音纠错、行业词库。

## 功能

- 全局快捷键（默认右 ⌥），Esc 取消；边说边识别，说完即插入
- 大模型润色：去口头禅、补标点、处理口误，不改原意
- 词库：热词、重点词、背景说明、错误写法自动替换、同音字纠正、行业词库
- 在历史里纠正说错的词，自动学成规则
- 6 种口述语言、5 种界面语言
- 历史与用量统计、iCloud 同步、可选语音增强（回声消除 + 降噪）

## 安装

**从源码**（macOS 14+、Xcode 15+）：

```bash
git clone https://github.com/rampagege/ChillTalk.git
cd ChillTalk
./scripts/install.sh   # 编译并安装到「应用程序」，之后不依赖 Xcode
```

首次使用前，在 Xcode 的 Signing & Capabilities 里把 Team 改成你自己的（免费 Personal Team 即可）。固定的签名能让系统记住麦克风和辅助功能权限。

**下载版本**：未经苹果公证，首次打开需到 系统设置 → 隐私与安全性 点「仍要打开」。

## 使用

1. 授予**麦克风**和**辅助功能**权限
2. 菜单栏图标 → 设置… → 语音识别：选服务商、填 API 密钥、点「测试连接」
3. 在任意输入框轻按右 ⌥ 说话，再按一次结束

## 隐私

录音只发给你选择的识别服务商，ChillTalk 不保存音频。API 密钥存在 macOS 钥匙串，不会同步或上传。历史和词库保存在本机，开启 iCloud 同步后另存一份到你的 iCloud 云盘。

## 开发

原生 Swift/SwiftUI，无第三方依赖。代码结构见 `ChillTalk/` 目录，界面文字在 `Localizable.xcstrings`。
